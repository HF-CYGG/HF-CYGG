## How I Build

**01 · 从真实问题开始**<br>
先确认需要解决的流程、数据或使用场景，让项目从明确需求出发。

**02 · 先让核心链路可靠运行**<br>
在功能可用的基础上，继续打磨界面、数据流、异常处理与性能。

**03 · 交付完整形态**<br>
把想法做成可长期使用的 Android App、Web 服务、Docker 镜像或其他可交付成果。
